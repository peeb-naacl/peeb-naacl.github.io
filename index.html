Explain a prediction. Edit its descriptions. Add a new class—without retraining.

Abstract

CLIP-based classifiers rely on familiar class names, which limits recognition when a name is new or rarely seen online. PEEB instead represents each class through natural-language descriptions of its visual parts, then matches those descriptions to detected image regions.

This language bottleneck makes fine-grained predictions explainable and lets users edit class definitions at inference time. The paper reports 88.80% top-1 accuracy on CUB-200 and 92.20% on Stanford Dogs-120 in the supervised setting, alongside strong zero-shot results.

Explanations grounded in visual parts

Which image details support a prediction? PEEB pairs each detected part with a description that a person can read and edit.

How does PEEB work?

The model matches the image and language at the part level, then combines the evidence into a class score.

1. Detect parts

Select embeddings for 12 bird parts and predict their bounding boxes.

2. Match descriptions

Compare each visual part embedding with its corresponding text descriptor.

3. Combine evidence

Sum the part–text dot products to compute a logit for each candidate class.

Results

Generalized zero-shot classification

PEEB is pretrained on Bird-11K and evaluated without downstream finetuning. In this setting, evaluation includes seen and unseen classes. CLIP and M&V use common class names; PEEB uses part descriptions.

Beyond birds: explaining dog classification

PEEB also works with six dog parts: head, ears, muzzle, body, legs, and tail. Its explanations connect image regions with the text descriptions used to score each candidate breed.

Datasets and limitations

Bird-11K contains 294,528 filtered images across 10,811 classes. Dog-140 extends the pretraining approach to dogs. The official implementation provides preparation instructions and model checkpoints.

Recognition depends on the quality of the descriptions and text encoder. Generated descriptions can contain errors, and occluded parts can make grounding difficult. See Section 7 for the limitations.
